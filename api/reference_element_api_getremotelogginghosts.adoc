= GetRemoteLoggingHosts
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 `GetRemoteLoggingHosts` 方法获取日志服务器的当前列表。



[[parameters]]
== Parameters

没有输入参数 `GetRemoteLoggingHosts`。



[[return-value]]
== 返回值

这 `GetRemoteLoggingHosts`该方法具有以下返回值：

|===
| Name | Description | Type 


 a| 
远程主机
 a| 
列出已配置为接收转发日志信息的主机的 IP 地址、FQDN 和端口信息
 a| 
xref:reference_element_api_loggingserver.adoc[日志记录服务器] 数组

|===


[[request-example]]
== 请求示例

此方法的请求类似于以下示例：

[listing]
----
{
   "id": 3386609,
   "method": "GetRemoteLoggingHosts",
   "params": {}
}
----


[[response-example]]
== 响应示例

此方法返回类似于以下示例的响应：

[listing]
----
{
   "id": 3386609,
   "result": {
      "remoteHosts": [
         {
           "host": "172.16.1.20",
           "port": 10514
         },
         {
           "host": "172.16.1.25"
         },
         {
            "host": "syslogs.lab.company.net",
            "port": 514
         }
      ]
   }
}
----


[[new-since-version]]
== 自版本以来的新增功能

从ONTAP 9.6 版本开始可用。
